# 정답 붙이기 — 채점용 30

## 2. 칸 (분류)

| 칸 | 기준 |
|---|---|
| 데이터 | 데이터 추출, 정보 수정, 오류 확인이 필요하다 |
| 계정권한 | 로그인 · 비밀번호 · 접근 권한이 막히거나 필요하다 |
| 유지보수 | 서버 · 환자 프로그램 · eCRF가 안 열리거나 오류가 난다, 설치 · 업데이트, 레지스트리 업데이트, eCRF 업데이트, 새 기능 추가 |
| 견적 | eCRF 구축 · eCRF 업데이트 · 유지보수의 비용을 묻거나 견적을 요청한다 |
| 기타 | 위 넷에 들지 않는다 |

**두 칸에 걸칠 때:** 데이터 → 계정권한 → 유지보수 → 견적 → 기타 순서로 앞 칸을 정답으로 한다.

## 3. 긴급도

| 값 | 기준 |
|---|---|
| 높음 | 레지스트리에서 입력이나 조회가 안 된다, 기능이 안 된다 |
| 보통 | 환자 데이터 수정, 데이터 추출, 그 밖의 유지보수, 새 기능 추가(부작용보고 탭 추가처럼 사소하지 않은 것), 비밀번호 분실 |
| 낮음 | 문의 · 견적 요청, 계정 · 권한 요청 |
